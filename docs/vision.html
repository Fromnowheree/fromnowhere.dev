The concept: Origin

Every project starts at the same point

In the FNW mark, the point under the F marks the place everything starts from. On fromnowhere.dev that point becomes the home page. One line leaves it for each project, and the site’s job is to show where each line goes, then send you there.

01The idea

A crossroad that looks like one

Your two favourite sites each wear a costume taken from their own world. That’s what makes them memorable, and it’s what fromnowhere.dev needs too.

The studio site has one constraint the others don’t: it’s the home of the Fromnowhere system, so it can’t step outside it the way ygo did. The answer is a costume the mark already wears. Separate plates on one platform, a single point where things start: that’s wayfinding. Transit maps, departure boards and signage plates are exactly what a crossroad looks like.

So the site reads as a small station. Calm, exact and dark, with clear signs, and lines leaving for very different places.

The rule that holds it together

A quiet station, loud destinations

fromnowhere.dev stays calm so the places it leads to can be as loud as they like. Their colours and type appear only inside their own framed windows, never on the station itself.

02Signature pieces

Five things only this site has

The route map

The home page hero

The point on the left, one line per project, each ending at a plate with its address. Lines are neutral at rest. The one you hover or focus turns accent, since in this system the accent is a line or a point. Lines draw out from the point once per visit, at the brand’s slow settle. Projects still being built are dashed, the way transit maps mark lines under construction. Try the map above.

The departures board

The project index

A table with line, destination, what it is, address and status. The status is real: a small job checks every address every few minutes, so “Running” means the site answered. No split-flap animation. The system rules out counting and typewriter effects, and a board that sits still reads as more trustworthy anyway.

Exit plates

You always know when you’re leaving

giogio.musicLeaves fromnowhere.dev

Every link that leaves the site is a signage plate with an arrow, the address and a plain “Leaves fromnowhere.dev”.

05Content

What lives in Payload

06Stack

The usual, on purpose

PartChoice
AppNext.js 16 (App Router) with Payload 3 in the same app, admin at /admin, Node with pnpm.
DataPostgres 17. Uploads on disk in a volume.
ServingDocker compose and Caddy with automatic HTTPS, Umami for cookieless stats. The scaffold started as a copy of NMT-PublicWeb, the most finished of the siblings: its infrastructure, hardening, language routing and contact relay, with the clinic layer replaced.
DesignThe Fromnowhere system, ported as fnwygo does it: tokens.css and bundle.css in src/styles/fnw, Inter in public/fonts, the React components from fnw.tsx. Site-only pieces (map, board, plates, windows) built from the same tokens.
LanguagesEnglish and Croatian. Payload’s localization (en, hr, falling back to en) for content, next-intl for interface strings, as NMT already does. hreflang links between the pairs.
MotionThe logo assembles once, lines draw once per visit, the board rows reveal on scroll, cross-page view transitions with the nav held still. Everything stops under reduced motion.
Domainsfromnowhere.dev and www go to this app. yugioh.fromnowhere.dev and, later, medical.fromnowhere.dev stay separate apps; the map only links to them.
HostingOne Fromnowhere server for the fromnowhere.dev family, with one shared Caddy in front of every app on it. Client sites like gati.hr keep their own servers. Images are built in CI, not on the server.
